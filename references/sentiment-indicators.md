# 散户情绪观测指标

如何从可观测的数据中推断散户的情绪状态和行为倾向。这些指标不需要高频数据，大多数通过公开渠道可以获取。

---

## 一、开户与入场指标

### 1. 新增投资者数量
- **数据来源**：中国结算（中国证券登记结算有限公司）月度数据
- **解读**：
  - 月新增低于100万：市场冷清，散户兴趣低
  - 月新增100-200万：正常水平
  - 月新增200万以上：市场热度上升
  - 月新增300万以上：情绪明显过热（2020年7月、2015年4-6月的数据）
- **逆向信号**：新增开户数创阶段性高点的月份，往往对应市场阶段性顶部

### 2. 百度指数
- **搜索关键词**："股票开户"、"炒股"、"股票"
- **解读**：
  - 搜索量温和上升：正常关注度提升
  - 搜索量暴涨至历史高位：散户蜂拥关注，情绪过热
  - 搜索量跌至冰点：散户彻底失去兴趣，可能接近底部
- **实用价值**：百度指数比官方开户数据更实时，可以做到周度甚至日度跟踪

### 3. 券商APP下载量
- **数据来源**：应用商店排行榜、七麦数据等
- **解读**：同花顺、东方财富等APP冲上免费榜前列 → 散户大规模入场信号

## 二、资金面指标

### 1. 两市成交额
- **解读框架**：
  - 成交量萎缩到极致（如两市成交低于5000亿）：市场极度冷清，散户无心交易
  - 成交量温和放大：正常情绪回暖
  - 天量成交（如两市超2万亿）：散户大规模参与，情绪亢奋
- **经典规律**："天量天价，地量地价"
  - 天量意味着买卖双方都充分表达，往往对应短期高点
  - 地量意味着无人问津，往往对应中长期底部区域

### 2. 融资融券余额
- **数据来源**：沪深交易所每日披露
- **解读**：
  - 融资余额温和增长：正常加杠杆行为
  - 融资余额快速攀升（如月增超过10%）：散户加大杠杆，风险偏好极端
  - 融资余额见顶回落：杠杆资金撤退，往往是调整前兆
- **为什么重要**：融资盘代表了散户中的"激进派"。融资余额的拐点往往是市场情绪的先行指标——借钱炒股的人对市场最敏感。

### 3. 北向资金（外资）流向
- **与散户的对照关系**：
  - 外资持续流入 + 散户观望：往往是较好的布局时机
  - 外资流出 + 散户追涨：散户给人接盘
  - 外资和散户同向：趋势可能延续
- **注意**：北向资金不能作为单一决策依据，但与散户情绪对照时很有价值。

## 三、基金与产品指标

### 1. 新基金发行规模与配售比例
- **情绪信号**：
  - 新基金发行困难、募资延长期限：市场底部区域
  - 新基金一日售罄、配售比例极低：情绪过热
- **典型案例**：
  - 2021年1月：多只基金一日售罄，配售比例低至10%以下，对应阶段性顶部
  - 2018年下半年：基金发行困难，多只产品募集失败，对应市场底部

### 2. "日光基"频率
- 一个月内出现3只以上一日售罄的基金 → 强烈过热信号
- 连续数月没有爆款基金 → 市场冷清

### 3. 基金仓位
- 偏股型基金平均仓位超过88%（"八八魔咒"）：可投资金接近枯竭，进一步上涨动能减弱
- 基金仓位处于低位：后续有加仓空间

## 四、社交媒体与舆论指标

### 1. 股吧/雪球/微博讨论热度
- **观测维度**：
  - 某股票股吧的日发帖量
  - 雪球话题的讨论激烈程度
  - 微博"股票"超话的活跃度
- **情绪判断**：
  - 发帖量暴增 + 帖子充满乐观情绪 → 过热
  - 发帖量骤减 + 剩下的帖子全是骂的 → 极度悲观

### 2. "段子手"指标
- 当股市段子开始刷屏朋友圈 / 微信群 → 散户关注度极高
- 当股市相关的梗频繁出现在非财经群 → 散户全面参与
- "韭菜"这个词在社交媒体上的出现频率，本身就是一个情绪指标

### 3. 微信群热度
- 股票群从冷清（无人说话）到活跃（频繁讨论个股）再到疯狂（推荐代码、晒收益）
- **个人观测法**：看看自己微信里的非投资群（家长群、爱好群、同事群）是否开始有人聊股票。越是非投资场景的人开始聊股票，说明散户参与度越高。

## 五、资产价格联动的散户信号

### 1. 低价股/垃圾股补涨
- **现象**：当一个板块或市场中，基本面差的股票开始大幅补涨
- **含义**：散户资金在"捡便宜"，好的已经涨高了不敢追，开始找还没涨的
- **信号**：垃圾股补涨往往是阶段性尾声的信号——因为该涨的都涨完了

### 2. 次新股炒作
- 次新股（上市不到一年的股票）因筹码干净、套牢盘少，是散户炒作的热门标的
- 次新股集体暴涨 → 散户炒作热情高涨

### 3. 可转债炒作
- 可转债T+0、无涨跌幅限制的特点吸引了大量散户短线交易者
- 可转债成交量暴增、出现天价转债 → 散户投机情绪亢奋

## 六、构建自己的情绪仪表盘

建议跟踪以下 5-7 个指标，构建一个简易的"散户情绪温度计"：

| 指标 | 冷（0-3分） | 温（4-6分） | 热（7-10分） |
|------|-----------|-----------|------------|
| 新增投资者 | 月增<100万 | 100-200万 | >200万 |
| 两市成交额 | <6000亿 | 6000-12000亿 | >15000亿 |
| 两融余额趋势 | 下降 | 持平 | 快速上升 |
| 新基金发行 | 募集困难 | 正常 | 一日售罄 |
| 股吧/雪球热度 | 冷清 | 正常 | 刷屏 |
| 微信群谈股频率 | 没人谈 | 偶尔 | 天天晒收益 |
| "开户"百度指数 | 低位 | 中位 | 飙升 |

**使用方式**：
- 总分 7-21：市场冷清，散户情绪低迷 → 散户参与度低，卖压小
- 总分 22-42：正常范围 → 没有极端信号
- 总分 43-70：情绪亢奋 → 散户全面参与，需警惕反向风险

**重要说明**：这个仪表盘是情绪参考，不是精确的买卖点。高分不一定立刻见顶，低分不一定立刻见底。它的价值在于让你知道"现在散户处在什么温度区间"，从而对一致性行为保持警惕。
